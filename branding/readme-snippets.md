# README Snippets

## CUDA

```markdown
# QuixiCore CUDA

QuixiCore CUDA is the NVIDIA CUDA implementation of the QuixiCore kernel library.

It is a standalone native implementation for NVIDIA GPUs starting from Ampere, covering both consumer and datacenter hardware. It shares no implementation code with the other QuixiCore backends.
```

## Metal

# QuixiCore Metal

QuixiCore Metal is the Apple Metal implementation of the QuixiCore kernel library.

It is a standalone native implementation for Apple Silicon, with integrations for MLX and PyTorch MPS. It shares no implementation code with the other QuixiCore backends.
