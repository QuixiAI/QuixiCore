# Format Conformance

Whether each backend's decoders agree with `specs/formats/`, checked against
`test-vectors/quant/` rather than asserted. A backend is *conformant* only if a
test in that repo consumes those vectors; anything else is an observation from
reading the source and is marked as such.

Generated by inspection on 2026-08-02. This table should become CI output —
see the note at the bottom.

## E8M0 (`specs/formats/mx-formats.md`)

Codes 0..254 decode to `2^(code-127)`; code 255 is NaN. Both edges are where
implementations diverge, and neither is reachable from data a conformant
producer emits — which is exactly why the divergence survived.

| Backend | code 0 | code 255 | Verdict | Checked by |
|---|---|---|---|---|
| CPU | `2^-127` | `NaN` | conformant | `tests/conformance/test_quant_vectors.cpp` |
| ROCm | `2^-127` (`e8m0_decode_exact`) | `NaN` | conformant | `tests/conformance/quant_conformance.cu` |
| ROCm | `+0.0` (`e8m0_decode_fast`, 7 families) | `+Inf` | divergent, documented | same |
| Metal | `2^-127` | `+Inf` | divergent at 255 | not yet checked |
| CUDA | `+0.0` | `+Inf` | divergent at both | not yet checked |
| XPU | — | — | no decoder found | — |
| Gaudi | — | — | not present | — |

`+0.0` at code 0 is sound *only* under the producer contract in
`mx-formats.md` — an all-zero block carries scale code 0 with all-zero
elements, so the product is zero either way. It is two ALU ops against a
table lookup or an `ldexp`, so it is a legitimate trade. What is not
legitimate is spelling it `e8m0_decode`, which is what made it invisible.

## E8M0, GGUF variant (`specs/formats/gguf.md`)

A separate contract, not a relaxation of the one above: ggml bit-puns the code
with no special case, so code 255 is `+Inf`. Matching it is required, because
the GGUF path exists to read the files ggml wrote.

| Backend | Verdict | Checked by |
|---|---|---|
| ROCm | conformant (`e8m0_decode_ggml`) | `tests/conformance/quant_conformance.cu` |
| Metal | matches by construction | not yet checked |
| CPU, CUDA | no GGUF decoder | — |

## Making this generated

Each backend's conformance test should emit a machine-readable line per format,
and this file should be assembled from those. Until then it is hand-written and
will drift — the same failure mode it exists to document. The two `not yet
checked` rows above are the immediate work: they are read from source, and
reading source is what produced the wrong three-way split this table replaced.
