# Naming

The canonical project name is QuixiCore.

The umbrella repository is:

```text
QuixiAI/QuixiCore
```

Backend repositories are:

```text
QuixiAI/QuixiCore-CUDA
QuixiAI/QuixiCore-Metal
QuixiAI/QuixiCore-ROCm
QuixiAI/QuixiCore-XPU
QuixiAI/QuixiCore-Gaudi
QuixiAI/QuixiCore-CPU
```

Use the following backend names in user-facing documentation:

- QuixiCore CUDA
- QuixiCore Metal
- QuixiCore ROCm
- QuixiCore XPU
- QuixiCore Gaudi
- QuixiCore CPU
