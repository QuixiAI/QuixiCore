# Lineage

QuixiCore is the umbrella contract for the QuixiCore backend family.

The project is designed for native accelerator implementations that expose a consistent library identity and behavior across hardware families while avoiding shared source code.

## Canonical Design Sentence

QuixiCore is one kernel library contract with six standalone native implementations: CUDA, Metal, ROCm, XPU, Gaudi, and CPU.

## Motto

Native implementations. Shared contract. No shared code.
