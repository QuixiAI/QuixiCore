# Roadmap V0

The v0 roadmap establishes the first public QuixiCore contract.

## Initial Work Items

1. Define QuixiCore Spec v0.1
2. Finalize backend repo names
3. Define CUDA backend scope
4. Define Metal backend scope
5. Define ROCm backend scope
6. Define XPU backend scope
7. Define Gaudi backend scope
8. Build initial kernel registry
9. Build initial quant format registry
10. Draft correctness methodology
11. Draft benchmark methodology
12. Create backend README template

## V0 Exit Criteria

- Backend registry names all five implementations.
- Kernel registry lists the initial contract families.
- Quant format registry lists initial target formats.
- Correctness and benchmarking docs define the first methodology.
- Backend README openings are captured in branding docs.
